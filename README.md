


#  Expense Splitter with Debt Simplification
A smart expense splitter that tracks shared costs and simplifies debts among group members. It minimizes transactions using debt simplification algorithms, making it ideal for trips, roommates, or group events.
## 📄 Description

A Java-based console application that helps groups track shared expenses and simplify settlements. It ensures fair splits of bills and minimizes the number of transactions between users using Greedy and Graph-based debt simplification algorithms.

This tool is ideal for roommates, friends on trips, or any group looking to manage shared finances efficiently.

---

##  Features

- Add users with unique IDs and names
- Record expenses with a payer and participants
- Display net balances of all users
-  Simplify debts using:
- Greedy Approach
    - Graph-based Min Cash Flow Algorithm
    -  Input validation and user-friendly prompts
